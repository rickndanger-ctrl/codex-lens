# Codex Lens Roadmap

Codex Lens is a glasses-first product. Smart glasses are the primary conversation, context-capture, and audio-feedback surface; the phone and local gateway support that experience.

## Current status

- Complete: validated conversation, Engineering Plan, approval, Execution Plan, execution-approval, and local task-queue contracts.
- Complete: deterministic text-only end-to-end protocol demo via `npm run demo`.
- Complete: guarded local Codex edit slice and iOS/glasses integration scaffolding.
- Not complete: production glasses hardware integration, on-device end-to-end validation, and a shippable mobile application.

## Next milestones

1. Complete and validate the Meta glasses capture and Bluetooth audio path on physical hardware.
2. Connect the glasses conversation experience to the approved local gateway protocol.
3. Add recovery, interruption, privacy, and long-running task feedback tests on device.

The text demo proves protocol continuity. It is not a change in product direction and does not substitute for the glasses-first experience.
